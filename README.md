# 自立活動 支援ナビ v1.8.7（Cloudflare Pages版）

学校内で共有できる静的PWAと、Pages FunctionsによるAI相談機能の配布パッケージです。支援カード310件を収録しています。

## 配布内容

- `site/` — アプリ本体、310カード、印刷・保存・オフライン機能、相談画面
- `functions/api/consult.js` — Cloudflare Workers AIを使う相談API
- `data/自立活動_支援ナビ_全310件_統合.json` — 編集・照合用データ

## 公開方法

1. ZIPを展開します。
2. Cloudflare Pagesの同じGit連携プロジェクトへ反映するか、Wrangler CLIからプロジェクトのルートで `npx wrangler pages deploy site --project-name=jiritsukatsudou` を実行します。
3. Pagesの設定でWorkers AIバインディング名を `AI` にします。
4. 公開後に `/api/consult?status=1` が `{"ready":true}` を返すことを確認します。

Cloudflareダッシュボードのドラッグ＆ドロップ公開ではPages Functionsが配信されません。AI相談を使う場合はGit連携かWranglerを利用してください。

## 保存・AI・オフライン

- 指導計画や実践記録は使っている端末のブラウザー内に保存され、他の端末とは同期しません。
- AI相談にはインターネット接続が必要です。質問と関連カード最大4件がCloudflare AIへ送られます。アプリは相談内容を保存せず、元PDF全文や外部検索結果は送信しません。
- カード検索などアプリ本体は、一度オンラインで開いた後、オフラインでも利用できます。
- 児童生徒の氏名・学校名・住所・診断名など、個人を特定できる情報は入力しないでください。
- Workers AIの無料利用には1日単位の上限があります。上限超過時はAI回答が停止する場合があります。

## v1.8.7の修正

国語・英語・数学・理科・社会・保健体育・技術家庭のワークシート案を、実際の問題文・語群や選択肢・記入欄・教員用の答えを含む構造化形式で生成します。印刷面に氏名欄や未完成の作業指示がないか確認し、形式が崩れた場合は照合カードに応じた教科別の簡易案へ切り替えます。簡易案も印刷条件を通らない場合は、未完成の用紙を返さず、再入力を案内します。漢字・英単語・計算式のような対象を問題文に明記し、選択肢や正答との整合性を確認します。回答はコピーでき、ワークシート案は児童用の面だけ印刷できます。AIは関連するアプリ内カード最大4件と組み込み済み資料の要約を使います。元PDF全文の読み込みや外部ウェブ検索は行いません。

前版で行った漢字見本欄の表示修正、自立活動関連項目の表記統一、検索カード照合・出典表示の改善も含みます。
